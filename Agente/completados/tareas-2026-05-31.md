## 311A-1 — Fase 4+5: Lifecycle emails + email_logs tracing + admin UI

- **Que:** Implementación completa del sistema de notificaciones email (Fase 4 y 5) y panel admin de trazabilidad.
  - **Fase 4:** 4 nuevas funciones lifecycle en `email.rs` (order_completed_client, order_cancelled_client, phase_delivered_client, problem_reported_client) + integración en order_lifecycle.rs, deliverables.rs, problems.rs.
  - **Fase 5:** Migration `20260531000000_email_logs`, `EmailLogRepository` (insert/list/count con filtro por template), logging integrado en las 12 funciones wrapper existentes, admin API endpoint `GET /api/admin/email-logs`.
  - **Admin UI:** `SeccionCorreo.tsx` + `SeccionCorreo.css` con filtro por plantilla, tabla paginada, estados vacío/carga/error. Registro en panel.ts, SidebarPanel.tsx, PanelIsland.tsx.
- **Archivos:**
  - `src/services/email.rs` — 4 nuevas funciones + logging en todas las wrapper
  - `src/repositories/email_log.rs` — Nuevo repositorio CRUD
  - `migrations/20260531000000_email_logs.*.sql` — Nueva migración
  - `src/handlers/admin_emails.rs` — Nuevo endpoint admin
  - `src/handlers/mod.rs` — Route registration
  - `src/handlers/order_lifecycle.rs` — Cancel email
  - `src/handlers/deliverables.rs` — Phase delivered email
  - `src/handlers/problems.rs` — Problem reported email
  - `frontend/src/api/admin-email.ts` — API client
  - `frontend/src/components/panel/SeccionCorreo.tsx` — Componente UI
  - `frontend/src/components/panel/SeccionCorreo.css` — Estilos
  - `frontend/src/data/panel.ts` — Tab registration
  - `frontend/src/components/panel/SidebarPanel.tsx` — Icon mapping
  - `frontend/src/islands/PanelIsland.tsx` — Import + case
- **Gotchas:**
  - SQLX_OFFLINE=true bloquea macros sqlx para tablas nuevas; se usó `query_as::<_, T>` no-macro en email_log.rs.
  - `order.client_name` no existe en Order struct; se usó `UserRepository::get_display_name()`.
  - El componente `Select` no acepta `options` prop, solo children `<option>`.
- **Sentinel:** No aplica (no se crearon reglas nuevas)
- **GLORY:** El repositorio `EmailLogRepository` y el endpoint admin son específicos de este proyecto; el patrón de logging en email.rs podría migrarse a glory-rs si otro proyecto lo necesita.
